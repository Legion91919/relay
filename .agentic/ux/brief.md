Users:       Kalahari Mobile prepaid customers on low-end Android phones (small screens, slow CPUs, 2G/3G that drops), all day, not tech-savvy.
Main job:    read and reply in a one-to-one chat fast, and always know whether a message was sent, delivered or read, even when the network drops.
Data:        partner displayName + presence (online / last seen), messages (body, sentAt, seq, status: sending|sent|delivered|read), connection state (online|connecting|reconnecting|offline), outbox count.
Tone:        warm, plain-spoken and light: sand and deep teal, big readable type, nothing that costs data or battery.
Must avoid:  web fonts, images, animation-heavy UI, colour as the only status signal, more than one accent colour, anything that looks like another messaging brand.
